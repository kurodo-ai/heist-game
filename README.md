Velvet Vault — a top-down midnight gallery heist. Slip past three patrolling guards and two sweeping cameras, pocket the paintings, gems and coin stacks ($3,050 in all), and reach the green EXIT door before the alarm hits 100 or the 150 seconds of night run out. Sneak with Shift, grab loot with E, drop smoke with Q.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network — the game is plain static files under `game/`.
